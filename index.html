      Допработы

      Статус двигается кнопкой в строке: выявлено → согласовано внутри → выставлено заказчику → принято (ДС). В бюджет и в акт допработа попадает только после «принято».

      Акты для субподрядчиков

      Акт собирается из принятых объёмов за период по кнопке. Номер пишется обратно в журнал, второй раз те же объёмы не заактировать.
